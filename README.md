# AURA & ARTISAN | Multi-Page Luxury Jewellery Web Architecture

A 7-page e-commerce website wireframe and interactive prototype synthesized from the 8 benchmark jeweller stores:
1. **Arika Jewels** (`arikajewels.shop`)
2. **Raviva Jewellery** (`ravivajewellery.com`)
3. **Chhail** (`chhail.com.au` / Shaya)
4. **Sawwaisa Jewellery** (`sawwaisajewellery.com`)
5. **Swashaa** (`swashaa.com`)
6. **Chahana Jewel Co** (`chahanajewelco.com`)
7. **Jewellery Khazana** (`jewellerykhazana.com`)
8. **Vijay Bangles** (`vijaybangles.in` / Meera Meenakari Bangles)

## 🎨 Home Page First Section: Rich Banner Images & Model Showcase

The first section of the home page (`index.html`) features a luxury editorial carousel with curated high-definition model photography corresponding to the four primary design pillars:
1. **Banner 1: The Royal Rajputana Bridal Collection** (*Sawwaisa & Jewellery Khazana reference*)
   - *Model Photography*: Indian bridal portrait in hand-set Pachi Kundan choker with hydro emerald drops.
2. **Banner 2: The Meera Meenakari Bangles** (*Vijay Bangles reference*)
   - *Model Photography*: Jaipuri hand-enameled peacock and lotus wrist stack with precision screw-locking kadas.
3. **Banner 3: 18K Anti-Tarnish & Waterproof Daily Luxe** (*Raviva, Arika & Chahana reference*)
   - *Model Photography*: Sunlit golden-hour model wearing layered paperclip chains, clover bracelets, and dome rings.
4. **Banner 4: Feeling Chhail: Oxidized 925 Silver Poetry** (*Chhail reference*)
   - *Model Photography*: Expressive bohemian model wearing statement silver chandbalis with chiming ghungroos.

### Interactive Banner Strip
Directly beneath the hero text is a **clickable banner preview strip** with mini photo thumbnails that allow visitors to instantly jump between banner collections.
